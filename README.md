## ⚓ Manifest

**AK — KV Global Freight Group** is a premium, enterprise-grade **digital freight-forwarding command center** — a single interactive platform unifying **air, ocean, customs, warehousing, and project cargo** under one operational dashboard. Built with a *"live dispatch telemetry"* design language, it turns a traditional logistics brochure site into something that feels like an active control tower: statuses pulse, shipments track in real time, and every inquiry routes straight into dispatch.

> *"Covering every freight discipline under one integrated group — because fragmented logistics is a liability, not a strategy."*

## ⚙️ Deploying Your Own Instance

```bash
# Clone the terminal
git clone https://github.com/altmashkhan-stack/ak-freight.git
cd ak-freight

# Install dependencies
npm install

# Boot the dispatch console locally
npm run dev
```

Visit `http://localhost:3000` — your local hub goes live.

```bash
# Ship it
npm run build && npm run start
```

Deploy with one command via **Vercel**:

```bash
npx vercel --prod
```
